# 🌿 Я в натуре Садовод

Умный помощник для садоводов, дачников и городских огородников.

## Что умеет

- 40 растений с аллелопатией, фенологией, SOS-триггерами
- Энциклопедия с умной модалкой
- Мой сад — личный таймлайн
- SOS Доктор — мгновенная диагностика
- Планировщик грядок с drag&drop
- Сравнение растений
- Гидропоника — 4 системы, 8 растений
- Скрещивание деревьев — 12 деревьев, 4 способа
- Народный календарь
- Геймификация — XP, уровни, стрики, 11 достижений
- Квесты дня, активность 90 дней, коллекция
- Оффлайн-первый PWA
- Тёмная тема

## Запуск

cd garden-universal-v13.0
py -m http.server 8000

Открой http://localhost:8000

## Установка как приложение

Android Chrome: Меню → Установить приложение
iPhone Safari: Поделиться → На экран Домой

## PWA-фичи

- Оффлайн-режим
- Установка на телефон
- Splash Screen
- Shortcuts (Мой сад, SOS, Планировщик)
- Автообновление SW
- Тёмная тема
