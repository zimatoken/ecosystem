# Я в натуре Мастер v1.0

Умный помощник для домашних работ.

## Что умеет
- 30 работ (электрика, сантехника, стены, полы, двери, окна, мебель)
- SOS Мастера (прорвало трубу, не работает розетка, запах газа)
- Калькулятор материалов (краска, плитка, ламинат, штукатурка)
- Дневник ремонта
- Геймификация (XP за работы)
- PWA + оффлайн

## Запуск
cd master-universal-v1.0
py -m http.server 8000
http://localhost:8000/master-universal-v1.0/

## Экосистема
4-е приложение в экосистеме:
- Садовод
- Автомобилист
- Повар
- Мастер
