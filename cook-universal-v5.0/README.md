# Я в натуре Повар v1.0

Умный помощник на кухне: рецепты, SOS-помощь, план меню.

## Что умеет
- 30 рецептов (план 200+)
- Что в холодильнике? (поиск по продуктам)
- SOS Повара (пригорело, пересолил, тесто не поднялось)
- Меню недели
- Избранное
- Геймификация (XP за блюда)
- PWA + оффлайн

## Запуск
cd cook-universal-v1.0
py -m http.server 8000
http://localhost:8000/cook-universal-v1.0/

## Экосистема
3-е приложение в экосистеме:
- Садовод
- Автомобилист
- Повар
